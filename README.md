# BTRT Awards 2026 Mock Nomination Platform

Static GitHub Pages prototype for tomorrow's mock test.

## How to use

1. Upload `index.html`, `styles.css`, and `script.js` to your GitHub Pages repository.
2. Open the GitHub Pages URL.
3. Test the flow:
   - Submit a Peer Nomination.
   - Prefill or submit an Official Company Package.
   - Review it in HR / HOD Dashboard.
   - Change status to Finalist.
   - Score it in Judges Pack.

## Important

This is a front-end mock only. It stores data in the browser using localStorage. Do not use real confidential employee data until a proper backend, access control, privacy controls and data retention policy are in place.
