# BTRT Awards 2026 Nomination Portal Mock

This is a static GitHub Pages prototype for testing the BTRT Awards workflow.

## Files to upload

- `index.html`
- `styles.css`
- `script.js`
- `README.md`

## Demo login

Use one passcode for all internal views:

`BTRT2026`

## What works

- Employee-facing peer nomination form
- Required submitter details and S.T.A.R. evidence
- Single reviewer / judge login gate
- HR / HOD / Director review workspace
- Director approval status
- Weighted company assessment
- Finalist shortlisting
- Judge scoring
- Current finalist ranking
- Demo data
- JSON and CSV export

## Important

This prototype stores data in browser `localStorage`. It is good for a mock test on GitHub Pages, but it is not a secure backend and should not be used for confidential employee data.

For a production version, connect the front-end to Microsoft SSO plus SharePoint List, Dataverse, Supabase, Firebase, or an n8n backend.
